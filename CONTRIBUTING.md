# Contributing to Zenmanage Angular SDK

Thank you for your interest in contributing to the Zenmanage Angular SDK.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature-name`

## Development

### Build

```bash
npm run build
```

### Test

```bash
npm test
npm run test:coverage
```

### Lint and Types

```bash
npm run lint
npm run type-check
```

### Formatting

```bash
npm run format:check
npm run format
```

## Pull Request Checklist

1. `npm run validate` passes
2. Unit tests cover behavioral changes
3. Documentation and examples are updated
4. CHANGELOG is updated

## Questions

Open a GitHub issue or contact support@zenmanage.com.
